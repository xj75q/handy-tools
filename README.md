
##### 【仓库作用】

本仓库主要放一些不同语言写的小工具，方便自己使用，现开源出来，有需要的也可以下载

- 使用语言：golang，python，c++，csharp，shell等
- 使用方式：在各自文件夹的README里有说明

##### 【go-tools】
go-tools文件夹内主要是使用go语言写的一些命令行工具，
包含：
- 文件重命名工具（含多种方式批量重命名）
- 图片格式转换工具（多种图片格式批量转换）
- mp4转换成mp3工具（可调速，调节音量等）
- 命令行内记录任务到滴答清单工具
- 命令行内发送碎片记录到flomo工具
- 命令行查看天气工具
- 命令行发送邮件工具
- 密码生成工具
- 扫描开放端口工具

##### 【go-widget】
go-widget文件夹内主要go语言写的可能用到的一些小组件：
包含：
- 封装log日志，使其不同等级带不同的颜色，方便排查问题使用
- 简单的不同限流实现方式
- 简单的redis分布式锁等
- 简单的基于etcd服务注册发现

##### 【py-tools】
py-tools 文件夹内主要是用python写的一些工具，
包含：
- pdf合并工具
- ppt转word工具
- ts文件合并成mp4工具
- 获取屏幕上的鼠标坐标工具

##### 【script-tools】
- shell脚本示例，linux上使用，是在定时在桌面弹出通知信息
- ahk脚本，win上使用，主要是在win上使用ank快捷方式
- powershell 脚本，win上使用，绑定微信的CPU占用核，降低微信对电脑的性能消耗

##### 【cpp-tools】
cpp-tools 主要是c++写的一些小工具，包含：
- 屏蔽微信任务栏消息闪烁工具（适用于win10）
- 任务栏隐藏模式下，彻底收到侧边不再弹出工具（方便某个软件全屏时候实现“真全屏”，而不是“伪全屏”）

##### 【csharp-tools】
- 快速记录内容 （GUI）
