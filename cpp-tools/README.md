##### 【hideIcon】
隐藏任务栏图标（只在win10上使用）

使用方法：

```
alt+1 选择窗口；
alt+2 隐藏该程序的任务栏图标； 
alt+3 恢复任务栏图标
```

注：主要针对微信消息的闪烁，只是隐藏任务栏图标，在主窗口还能聊天

具体使用：

```
1> 微信点击置顶
2> 点击运行该软件hideIcon.exe
3> 鼠标指针移动到要选择的窗口中（比如微信）
4> 使用快捷键（其中任意2个）：
alt+1 选择窗口；
alt+2 隐藏该程序的任务栏图标； 
alt+3 恢复任务栏图标
5> 微信取消置顶
```

注：对于微信，需要先置顶再操作；对于其他软件，比如网易云，可以跳过1和5。（只在windows上有效果）

##### 【hideWinTaskbar】
隐藏任务栏

说明：
win的任务栏区域虽然可以设置成隐藏，但是一旦触碰到该区域就会弹出任务栏，在某些软件全屏模式下影响观感，开发了一个小功能

使用方式：
1> 启动隐藏任务栏功能
```
任务栏点击右键 | 任务栏设置 | 在桌面模式下自动隐藏任务栏 | 开
```

2> 双击hideWinTaskbar，启动程序

3> 按键说明
```
shift + F1  显示任务栏
shift + F2  隐藏任务栏
```
